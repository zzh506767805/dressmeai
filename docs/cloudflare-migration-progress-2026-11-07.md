- AI 提交前原子领取任务，重复请求复用已提交任务；图片输入只允许本人上传/保存或站内样例。客户端不再能伪造成功结果或因轮询超时退回正在生成的次数。支付验证增加登录与付款归属校验，并修正解锁失败后刷新误判为已解锁的情况。原子 SQL 日期与 Prisma D1 的 ISO 日期格式对齐。

- 支付通知改用 Workers 支持的异步签名校验，验签失败返回 400，业务暂时失败返回 503 让 Stripe 重试。续费通知加入事件去重与账单记录，订阅更新不再重置已用次数；较旧状态通知不能覆盖较新的状态。新增初始 D1 建表文件和运行时文件的 lint 排除。

- 新增真实本地 D1 的并发与故障测试：末次额度争抢、请求/失败/付款重试去重、事务中途失败回滚、订阅/续费重放、历史解锁与签名失效。测试只操作隔离的虚构账户，不扣真实款或调用收费 AI。
